# motorola-6845

The Motorola 6845 CRT controller.

| Crate | Registry |
|---|---|
| [`emu198x-motorola-6845`](crates/emu198x-motorola-6845) | [crates.io](https://crates.io/crates/emu198x-motorola-6845) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the BBC Micro, Amstrad CPC and Commodore PET.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
